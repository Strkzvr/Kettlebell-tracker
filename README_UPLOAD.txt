TRAINING & CHALLENGE TRACKER — CLOUDFLARE PAGES

Что загружать:
  Загрузите ВСЮ папку целиком в Cloudflare Pages: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, _headers.

Самый простой вариант через Direct Upload:
  1. Cloudflare Dashboard → Workers & Pages → Create application → Pages → Upload assets.
  2. Перетащите содержимое этой папки (или ZIP, если интерфейс его принимает как assets package).
  3. После публикации откройте выданный *.pages.dev адрес на iPhone.
  4. Safari → Поделиться → На экран «Домой».

Хранение данных:
  Данные находятся в localStorage конкретного адреса сайта. Перед сменой домена/URL скачайте полный JSON-бэкап и восстановите его на новом адресе.

Совместимость:
  Старый JSON, состоящий только из массива тренировок, приложение продолжает импортировать. Полный новый JSON сохраняет тренировки + челленджи.

Обновление v1.1:
  История тренировок теперь компактная и сворачиваемая. По умолчанию все тренировки свернуты; можно раскрывать по одной или использовать кнопки «Развернуть все» / «Свернуть все».

Обновление v1.2:
  - Новый/текущий челлендж автоматически показывается первым на главном экране.
  - Первый актуальный челлендж визуально выделен.
  - Челлендж считается завершённым, если закончился его период ИЛИ достигнуто 100% цели.
  - Завершённые челленджи автоматически уходят в сворачиваемый блок «Завершённые челленджи».
  - Каждый завершённый челлендж внутри блока также можно раскрывать отдельно.
  - Ручной «Архив» остаётся отдельным для окончательно убранных челленджей.
